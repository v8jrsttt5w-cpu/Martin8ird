## 快速启动

| 你说什么 | 发生什么 | 走哪个子系统 |
|---------|---------|------------|
| `记录选题` | 想法存入选题箱 | 🎯 选题引擎 |
| `写脚本` | 检索素材→套模板→出脚本 | ✍️ 创作工坊 |
| `生成标题` | 基于方法论输出5个标题 | ✍️ 创作工坊 |
| `优化开头` | 读取完播率→优化前5秒 | ✍️ 创作工坊 |
| `找素材` | 全局搜索钩子/金句/概念 | 🧠 素材大脑 |
| `数据复盘` | 输入数据→写入数据表→建议 | 📊 数据驾驶舱 |
| `分析收入` | 收入占比→趋势→优化 | 📊 数据驾驶舱 |
| `周报` | 汇总数据→亮暗点→建议 | 📊 数据驾驶舱 |
| `拆解对标账号：xxx` | 深度分析→存入对标库 | 🔍 竞品雷达 |
| `探索选题` | 对标分析→5个选题建议 | 🔍 竞品雷达 |
| `探索竞品` | 搜索新博主→加监控 | 🔍 竞品雷达 |
| `生成话术` | 读取话术库→直播话术 | 💰 商业引擎 |
| `分析这个品` | 评估带货潜力 | 💰 商业引擎 |
| `运行日常` | 热点+竞品+数据一键check | 全系统 |
| `品牌规划` | 品牌/课程方案草拟 | 💰 商业引擎 |

🧠 素材大脑    03-方法论沉淀/     概念库+方法论+已发布归档

               06-业务运营/       收入+品牌规划+课程
