# 带货转化方法论

> 马丁老师账号的带货规律总结。本文档是「活的」。

## 一、已验证的转化规律

### 规律1：信任铺垫 → 产品引入
- 先用内容建立信任，再推产品
- 信任建立方式：专业知识展示 / 个人经验分享 / 真实使用场景

### 规律2：痛点唤醒 → 产品解决
- 先让观众意识到「我确实有这个问题」
- 再展示产品就是答案

### 规律3：价格锚定 → 优惠冲击
- 先建立产品价值认知（这东西值多少）
- 再抛出优惠价格，制造「赚到了」的感觉

### 规律4：从众效应 → 临门一脚
- 「已经卖了XXX单」「大家都在买」
- 限时/限量制造紧迫感

## 二、话术结构模板

### 标准带货话术结构
1. 引入（15秒）：建立场景和信任
2. 痛点（20秒）：唤醒需求
3. 产品展示（30秒）：卖点 + 使用效果
4. 价格对比（15秒）：锚定 + 优惠
5. 逼单（10秒）：限时限量 + 引导下单

### 高转化话术要素
- 数字具体化：「3天见效」比「效果很快」好
- 场景具体化：「上班挤地铁时」比「出门时」好
- 身份标签化：「小个子男生的痛」比「男生的痛」好
