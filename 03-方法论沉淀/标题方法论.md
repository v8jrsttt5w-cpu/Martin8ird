# 标题方法论

> 基于数据总结的爆款标题规律。本文档是「活的」，随着数据持续迭代。

## 一、已验证的标题规律

### 规律1：数字 + 痛点
- 句式：「[数字]个[场景]的[痛点]，第[数字]个太真实了」
- 适用：痛点共鸣型内容
- 数据支撑：待积累

### 规律2：身份标签 + 结果
- 句式：「[身份标签]一定要[行动]，因为[结果]」
- 适用：人群精准内容

### 规律3：反常识 + 解释
- 句式：「为什么[反常识结论]？[一句话解释]」
- 适用：认知颠覆型内容

### 规律4：悬念 + 省略
- 句式：「[惊人事实]，原因竟然是……」
- 适用：好奇心驱动内容

### 规律5：对比型
- 句式：「[之前状态] VS [现在状态]，我只做了一件事」
- 适用：改变/成长类内容

## 三、标题拆解 · 什么是好标题

### 案例1：「别再傻傻地拍大黑脸了！三步用免费阳光拍出杂志感」（2026-05-13）

**为什么好**：

| 要素 | 体现 |
|------|------|
| 痛点可视化 | 「大黑脸」比「逆光脸黑」生动100倍，观众一秒脑补画面 |
| 情绪冲突 | 「别再傻傻地」=否定旧做法，制造纠正欲 |
| 降低门槛 | 「免费阳光」把侧逆光翻译成零成本的东西，观众觉得"那我也可以" |
| 数字承诺 | 「三步」=简单可执行，降低观看压力 |
| 结果前置 | 「杂志感」=终极效果承诺，给你看下去的期待 |

**可复用的标题公式**：
> 别再[傻瓜行为]了！[数字]步用[免费/低成本资源]拍出[高端效果]
