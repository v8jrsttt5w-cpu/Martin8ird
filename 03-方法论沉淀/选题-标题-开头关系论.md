# 选题 · 标题 · 开头 三者关系论

> 选题决定谁会点进来，标题决定他们怎么点进来，开头决定他们会不会留下来。

## 一、三者逻辑关系

```
选题（What）  →  决定内容天花板
标题（How）   →  决定点击率
开头（Hook）  →  决定完播率
```

## 二、好选题的特征
- 有争议性（让人想评论）
- 有共鸣（让人想转发）
- 有信息差（让人想收藏）
- 有情绪（让人想点赞）

## 三、好标题的特征
- 说人话，不是新闻标题
- 暗示价值（看完能获得什么）
- 制造好奇心缺口
- 字数控制在 15-25 字

## 四、好开头的特征
- 第一帧有视觉冲击
- 3秒内抛出钩子
- 5秒内建立观看期待
- 与标题形成「标题抛钩 → 开头收线」的配合

## 五、案例拆解

### 沙面侧逆光支架教学（2026-05-13）

| 环节 | 内容 | 分析 |
|------|------|------|
| 选题 | 侧逆光+支架一个人拍杂志感 | 痛点精准（一个人拍照的困境），有信息差 |
| 标题 | 别再傻傻地拍大黑脸了！三步用免费阳光拍出杂志感 | 痛点可视化（大黑脸）、降低门槛（免费阳光）、数字承诺（三步） |
| 开头 | 成片前置+品牌签名 | 结果前置建立期待，品牌签名建立人设 |
| 三者配合 | 标题喊「别拍大黑脸」→开头直接展示拍对了的效果→观众想看三步是什么 | 标题抛钩→开头收线，逻辑闭环 |
