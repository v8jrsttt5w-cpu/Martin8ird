# 发给豆包 · 账号拆解提示词

> 截竞品账号主页 + 代表作视频列表，发豆包 + 下面这段话。

---

## A. 账号主页分析（截图账号主页）

```
请分析这个抖音账号的主页截图，提取：

【基本信息】
账号名：
粉丝数：
总获赞：
作品数：
简介/个签：
是否有橱窗/店铺：
IP属地：

【账号定位】
一句话总结他的定位：
目标人群：
人设标签：

【视觉风格】
头像风格：
封面风格是否统一：
主要色调：
```

---

## B. 热门作品分析（截图作品列表页，最好包含播放量数据）

```
请逐条提取这个账号的作品列表数据（按截图顺序）：

| 序号 | 标题 | 点赞 | 类型（教学/穿搭/Vlog/带货/日常） |
|------|------|------|------|
```

---

## C. 单条爆款拆解（截图单条视频详情页）

```
请分析这条爆款视频的后台数据：

【基础数据】
标题/内容主题：
时长：
播放量：  点赞：  评论：  转发：  收藏：

【完播与留存】
完播率：
前5秒留存：
平均播放时长：

【开头分析】
开头前3秒说了什么/展示了什么：
有没有口播/字幕/特效：
用了什么钩子类型（疑问/反常识/数字痛点/身份标签）：

【节奏分析】
每条信息/镜头的切换频率：
BGM类型：
口播语速（快/中/慢）：

【变现分析】（如果有）
是否挂了橱窗/小黄车：
挂了什么产品：
评论区是否有引导购买的话术：
```
