# 发给豆包的截图分析提示词

> 每次发一张截图给豆包，按截图类型选对应的提示词。返回结果粘贴给 Claude。

---

## 类型A：视频数据截图（创作者后台单条视频详情）

复制下面这段话：

```
请提取截图中的以下数据，严格按格式输出。不要做任何分析，不要编造数据。

播放量：
点赞：
评论：
转发：
收藏：
完播率：
前5秒留存：
发布时间：

⚠️ 重要规则：
- 截图里没有的字段输出「无」
- 百分比保留一位小数（如 42.1%）
- 播放量是 0 就输出 0
- 不要猜测账号（马丁鸟/马丁老师），不要输出账号字段
- 不要给我任何分析和评价
```

---

## 类型B：带货数据截图（电商后台，含挂车/橱窗/直播）

复制下面这段话：

```
请提取截图中的带货数据，严格按格式输出。不要做任何分析。

GMV（成交金额）：
观看次数：
订单数：

如果有以下字段也输出：
曝光人数：
点击率/进橱率：
转化率/访购率：
客单价：
千次观看成交：
```

---

## 类型C：账号总览截图（粉丝数/汇总数据/达人排名）

复制下面这段话：

```
请提取截图中的账号总览数据，严格区分以下三类信息：

【粉丝数据】
粉丝数：

【带货数据】
30天总GMV：
数据时间范围：
按渠道拆分（短视频/直播/图文/商品卡/其他）：

【达人排名】（如果有）
排名百分比：
较前7日变化：
同层级总人数：

⚠️ 重要：达人排名数据≠粉丝数，绝对不要混淆！截图里没有粉丝数就说「无」，不要用排名数字替代。
```
