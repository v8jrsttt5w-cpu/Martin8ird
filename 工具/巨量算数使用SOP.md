## 一、选题热度预判（每周必做）

### 1.1 算数指数：一条选题值不值得拍

```
操作路径：首页搜索框 → 输入关键词 → 查看「算数指数」
```

**示例：**
你想拍「小个子男生怎么选裤子」，先搜这几个词看热度：

| 搜什么 | 看什么 |
|--------|--------|
| 小个子穿搭 | 近3年热度趋势（是上升→还是平稳→还是下降↓） |
| 男生穿搭 | 对比热度，算竞争度 |
| 显高穿搭 | 是否有季节爆发点 |
| 拍照技巧 | 关联搜索词有哪些（发现新选题方向） |

**决策标准：**

| 热度趋势 | 拍不拍 |
|---------|--------|
| ↑ 近30天持续上升 | ✅ 立即拍，在爆发前卡位 |
| → 平稳但高 | ✅ 常青选题，随时能拍 |
| ↓ 持续下降 | ❌ 话题在衰退，放弃 |
| 📈 周期性波动 | 🟡 在峰值前1-2周准备 |

> 💡 搜完把截图的趋势线保存到 `选题管理/` 文件夹，以后写脚本时引用

### 1.2 关联分析：发现新选题方向

```
操作路径：搜索结果 → 下滑看「关联搜索」
```

巨量算数会告诉你：搜「小个子穿搭」的人还搜了什么。

**示例发现：**

```
搜「小个子穿搭」→ 关联搜索：
├── 小个子男生穿搭 → 直接选题
├── 165男生穿搭 → 你的精准标签
├── 小个子裤子推荐 → 带货入口
├── 男生怎么穿显高 → 教学选题
└── 身材比例穿搭 → 可做系列
```

> 把关联词里你没做过的方向拉到选题收集箱

## 二、内容词云：知道用户在搜什么（每周+拍前查询）

### 2.1 关键时期热点预判

```
操作路径：算数指数 → 搜关键词 → 看时间趋势
```

**固定节点提前查询：**

| 节点 | 搜索词 | 提前多久查 |
|------|--------|----------|
| 毕业季 | 毕业照/毕业穿搭 | 提前3周 |
| 618 | 618穿搭/618好物 | 提前2周 |
| 暑假 | 暑假穿搭/出游拍照 | 提前2周 |
| 开学季 | 开学穿搭 | 提前3周 |
| 国庆 | 旅行穿搭/旅行拍照 | 提前2周 |
| 双11 | 双11清单/必买 | 提前3周 |
| 春节 | 过年穿搭/新年拍照 | 提前10天 |

> 在DAILY-BRIEF的排期表里提前标注这些节点

### 2.2 人群画像：确认选题打没打对人

```
操作路径：算数指数搜关键词 → 点「人群画像」
```

**看什么：**

| 维度 | 关注点 |
|------|--------|
| 性别分布 | 你的内容吸引的是男是女？和预期一致吗 |
| 年龄分布 | 是学生（18-23）还是打工人（24-30） |
| 地域分布 | 一二线还是下沉市场？影响选题的「场景感」 |

**实用示例：**
如果发现「小个子穿搭」搜索者60%是女性——
→ 她们可能在帮男朋友/弟弟搜
→ 标题里加「帮你男朋友收藏」「发给那个165的男生」

## 三、自家数据对比（每周看一次）

### 3.1 你的内容关键词 vs 大盘

你的视频标题里用的词，在大盘上的搜索热度高吗？

```
你的标题用了「对镜自拍」
→ 巨量算数搜「对镜自拍」→ 看热度
→ 热度高 = 你押中了好词
→ 热度低 = 换成更热的表达
```

### 3.2 发现你的流量词

去抖音创作者后台拉你的视频数据，找到播放最高的5条视频的**标题关键词**。

用巨量算数搜这些词，对比热度：

```
你的爆款标题关键词 → 巨量算数热度 → 结论
「对镜拍」→ 热度高 → 继续用
「拍照姿势」→ 热度极高 → 加大频率
「阴天拍照」→ 热度中等 → 常青可复用
```

## 四、竞品关键词偷窥（每月）

### 4.1 反推竞品的关键词策略

竞品最近发的内容偏向什么话题？去巨量算数搜搜看这个词是不是在上升。

```
俊杰哥哥最近发了「暗调街拍教程」
→ 巨量算数搜「暗调」「街拍」→ 看趋势
→ 上升 = 他注意到了趋势，你也可以做（找到差异化角度）
→ 平稳 = 他在做常青内容，你也该有对应的内容
```

### 4.2 找对标还没覆盖的蓝海词

搜你赛道的核心词，看「关联搜索」里有没有竞品没覆盖的。

```
搜「小个子穿搭」→ 关联搜索「小个子男生约会穿搭」
→ 去看对标账号有没有做这个话题
→ 没做 = 你的蓝海
```

## 五、热榜监控（3天一次）

### 5.1 抖音热榜 vs 巨量算数

抖音App里「热榜」看的是**此刻什么火**，巨量算数看的是**什么在持续热**。

| | 抖音热榜 | 巨量算数 |
|------|---------|----------|
| 时效 | 实时的 | 近7天/30天趋势 |
| 用途 | 蹭即时热点 | 判断选题方向 |
| 怎么用 | 每天刷一下 | 每周查一次 |

### 5.2 搜索上升词

```
操作路径：巨量算数首页 → 搜索上升趋势
```

找摄影/穿搭赛道的上升词，这就是接下来会火的选题方向。

## 六、日常操作清单

### 每次选题深化前（2分钟）
- [ ] 把选题核心关键词在巨量算数搜一下

- [ ] 看关注赛道的搜索上升趋势
