# 蝉妈妈使用SOP

> 专为马丁鸟/马丁老师定制的蝉妈妈操作手册。
> 网址: chanmama.com | APP: 应用商店搜「蝉妈妈」

---

## 一、竞品拆解（每周1-2次）

### 1.1 查看对标账号最新数据

```
操作路径：达人搜索 → 输入抖音号/昵称 → 进入达人详情页
```

**看什么：**

| 模块 | 指标 | 怎么看 |
|------|------|--------|
| 概览 | 粉丝数/涨粉趋势 | 最近7天涨了还是跌了？涨=内容对了 |
| 视频分析 | 近30天发布量、平均播放 | 更新频率 vs 你的频率 |
| 爆款视频 | 播放最高的3-5条 | **点进去看完整数据** |
| 粉丝画像 | 性别/年龄/地域 | 跟你的粉丝重合度 |

### 1.2 拆解一条爆款视频

```
操作路径：达人详情页 → 视频分析 → 点开一条爆款 → 看数据
```

**关键数据解读：**

| 数据 | 好的标准 | 怎么用于自己 |
|------|---------|------------|
| 播放量 | 该账号平均播放的3倍+ | 这条选题方向值得跟进 |
| 点赞率 | >3% | 内容质量说服力强，抄结构 |
| 评论率 | >0.5% | 钩子/话题有争议性或互动性 |
| 转发率 | >1% | 实用性强或情绪共鸣强 |
| 收藏率 | >3% | 干货型内容，信息密度高 |
| 完播率 | >15%（短视频） | 节奏/结构值得学习 |

### 1.3 自动发现新对标账号

```
操作路径：达人搜索 → 按条件筛选
```

**马丁鸟筛选条件：**
- 分类：摄影/颜值
- 粉丝量：5万-50万（同量级）
- 内容标签：拍照技巧/手机摄影

**马丁老师筛选条件：**
- 分类：穿搭/时尚
- 粉丝量：1万-20万
- 内容标签：小个子穿搭/男生穿搭

> 💡 发现新账号 → 截图3条代表作 → 发给AI拆解 → 写入对标账号库

## 二、选题热点（每天5分钟）

### 2.1 热搜词监控

```
操作路径：热搜词 → 选择「摄影」或「穿搭」分类
```

**看什么：**
- 热度趋势（上升↑ / 平稳→ / 下降↓）
- 相关视频数（竞争度：越少越好蹭）
- 近7天热度变化

**判断能不能蹭：**

| 热度 | 竞争度 | 决策 |
|------|--------|------|
| ↑ 上升 | 低（<1万条） | ✅ 立刻蹭，蓝海期 |
| ↑ 上升 | 高（>10万条） | ⚠️ 用差异化角度切入 |
| → 平稳 | 任意 | 🟡 常青选题，随时做 |
| ↓ 下降 | 任意 | ❌ 过了，放弃 |

### 2.2 热门BGM发现

```
操作路径：素材库 → 热门音乐 → 筛选「摄影」/「穿搭」
```

**记录格式（写入BGM库）：**
```
| 曲名 | 使用人数 | 近7天趋势 | 适合场景 |
```

### 2.3 爆款视频选题反推

```
操作路径：视频榜单 → 筛选「摄影」或「穿搭」→ 近7天 → 按播放量排序
```

**拆解每一条爆款：**
- 标题用了什么句式？（数字？悬念？对比？）
- 封面有什么特征？（人物占比？文字？色调？）
- 开头3秒做了什么？（钩子类型：悬念/效果前置/反常识/痛点）
- BGM是什么风格？

> 每周从榜单里找 3 条可复用的选题 → 写入选题收集箱

## 三、带货选品（马丁老师专用）

### 3.1 找潜力商品

```
操作路径：商品分析 → 按品类筛选「男装」→ 按销量/GMV排序
```

**筛选标准：**

| 维度 | 标准 |
|------|------|
| 品类 | 裤子/上衣/外套（小个子刚需） |
| 价格带 | ¥50-200（学生可承受） |
| 佣金率 | >15%（太低不划算） |
| 转化率 | >2%（说明品本身没问题） |
| 关联达人 | 中小达人为主（非头部垄断） |

### 3.2 分析一个品的带货潜力

```
操作路径：商品详情 → 看近30天趋势
```

**品好不好，看这3个数字：**

| 指标 | 好 | 一般 | 差 |
|------|-----|------|-----|
| 转化率 | >3% | 1-3% | <1% |
| 退货率 | <10% | 10-20% | >20% |
| 关联视频数 | 10-50条 | 50-200条 | >200条(竞争大) |

### 3.3 反推竞品带货话术

```
操作路径：商品详情 → 关联视频 → 按GMV排序 → 看Top3带货视频
```

**逐条分析：**
- 开头怎么引入这个品的？
- 怎么展示上身效果的？
- 尺码推荐怎么说的？
- 逼单用什么理由？

> 好的话术直接收录到「话术库」

## 四、直播复盘（马丁老师开播后用）

### 4.1 自己直播数据

```
操作路径：我的直播 → 选择日期 → 查看数据
```

**必看指标：**

| 指标 | 健康线 | 优化方向 |
|------|--------|---------|
| 平均在线 | >50人 | 开场钩子不够吸引 |
| 停留时长 | >2分钟 | 品展示节奏太慢 |
| 互动率 | >5% | 没引导评论/点赞 |
| 成交转化 | >2% | 逼单话术不够狠 |
| UV价值 | >¥0.5 | 选品价格带偏低 |

### 4.2 对标直播间拆解

```
操作路径：直播榜单 → 搜对标达人 → 看直播回放数据
```

**记录：**
- 直播时长、时间段
- 带货品数和品类配比
- 最高在线发生在哪个品
- 用什么逼单方式
