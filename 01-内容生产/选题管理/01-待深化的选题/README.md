# 待深化的选题

> 从选题收集箱进入脚本开发前的中间层。这里放「已经决定要做，但还没成稿」的选题。

## 使用规则

- 从 `00-选题收集箱.md` 选中后，复制到本目录单独建文件。
- 文件名：`YYYY-MM-DD-选题标题.md`。
- 深化完成后，脚本正文转入 `脚本库/马丁鸟/` 或 `脚本库/马丁老师/`。

## 模板

```markdown
# 选题标题

## 选题描述

## 目标账号
- 马丁鸟 / 马丁老师

## 可复用素材
- 核心概念：
- 金句：
- 爆款结构：
- 已发布参考：

## 初步结构
- 开头：
- 中段：
- 结尾：

## 待确认
- 拍摄素材：
- 商品/场景：
- 发布时间：
```
