# 短视频脚本模板

> 每次写脚本时套用。选对应类型模板→填内容→拍。

---

## 模板一：摄影教学类

```
【钩子 0-3s】
你一定不知道，[反常识/悬念内容]

【问题 3-8s】
很多人拍照 [常见错误]，结果就是 [不好的效果]
比如这样 → [错误示范画面/图片]

【方法 8-20s】
正确做法：
第一步 [具体动作]，这样 [效果]
第二步 [具体动作]，这样 [效果]
第三步 [具体动作]，这样 [效果]

【成片展示 20-25s】
看效果 → [Before vs After 对比]

【引导 25-30s】
"还想学什么拍照技巧？评论区告诉我"
```

## 模板二：穿搭展示类

```
【钩子 0-3s】
[穿搭效果前置] 先看全身效果

【场景 3-8s】
今天穿这套去了 [场景]，[遇到了什么/感受到了什么]
重点看这条 [单品]，因为它 [核心卖点]

【细节 8-18s】
[多角度展示：正面/侧面/背面]
面料：[描述]
版型：[描述 — 重点说对小个子友好在哪]
搭配思路：[上衣怎么配/鞋子怎么配]

【尺码参考 18-22s】
我 165/[X]斤，穿 [尺码] 刚好

【引导 22-30s】
链接在橱窗/评论区
想看更多小个子穿搭，关注我
```

## 模板三：摄影师日常 Vlog

```
【钩子 0-3s】
今天有个陪拍客户/今天去 [地点] 拍照

【过程 3-20s】
[自然的拍摄过程 + 旁白]
"今天这个场景光线很 [X]，所以我用了 [设备/参数]"
[拍摄中的互动/趣事]
[环境空镜穿插]

【成片 20-25s】
"看看成片 →" [作品展示]

【金句收尾 25-30s】
"摄影让我发现，[感悟/金句]"
```

## 模板四：带货测评类（马丁老师）

```
【钩子 0-3s】
这件 [单品] 我穿了 [X] 天，洗了 [X] 次

【痛点 3-8s】
小个子买 [这类单品] 最怕什么？[痛点1]、[痛点2]、[痛点3]

【实测 8-20s】
[展示穿着效果：多角度]
[展示细节：做工/面料/弹性]
[说明这件怎么解决了痛点]

【尺码 20-23s】
我 165/[X]斤穿 [尺码]，你们参考

【成交 23-30s】
链接在橱窗
[价格] [优惠]
```

---

## 使用说明

1. 写脚本时选模板 → 填括号里的内容 → 发给 Claude Code 润色
2. 每条脚本必须包含：**文案 + Tag + 封面参考**
3. 发布后把脚本移到 `已发布内容/` 归档
4. 爆款脚本标注数据，反哺到结构库

---

## 发布信息模板（每条脚本必填）

### 文案
```
[15-30字的短视频文案，口语化，说人话]
```

### Tag
`#标签1` `#标签2` `#标签3` `#标签4` `#标签5`

### 封面参考
[描述封面视觉：什么画面+什么文字+什么构图]

> 文案核心原则：说痛点不说术语。不要"侧逆光拍摄教程"，要"别再拍大黑脸了"。
