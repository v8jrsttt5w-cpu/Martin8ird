## AI 生图提示词

> 使用方式：二选一。
> **方案A**（推荐）：用沙面成片当参考图 → 提示词A1/A2
> **方案B**：用旧视频截图当参考图 → 提示词B1/B2，可顺便换掉穿搭

---

### 方案A · 沙面成片做参考（不用换穿搭）

**图A1 · 光位错误版**

发给GPT时附带一张沙面全身成片 + 下面这句话：

```
参考这张照片，生成一张"拍错了"的版本。保持同一个人、同一套衣服、同一个沙面地点，但把光线改成：太阳在人物正前方（正面光），导致背景过曝发白，人物脸部被强烈的直射光打出难看的硬阴影。整体看起来像不懂光线的人随手拍的。竖屏3:4，真实手机照片质感，不要专业修图感。
```

**图A2 · 支架高度错误版**

发给GPT时附带同一张沙面全身成片 + 下面这句话：

```
参考这张照片，生成一张"拍错了"的版本。保持同一个人、同一套衣服、同一个沙面地点，但把拍摄角度改成：相机位置高于眼睛、从上往下俯拍，导致人物显得矮胖、头大身小、腿被压缩得很短。地面占了画面太多比例，构图失衡。自然下午光线但没用任何打光技巧。竖屏3:4，真实手机照片质感。
```

---

### 方案B · 旧视频截图做参考（可换穿搭+场景）

上传旧视频截图给GPT，附带以下提示词：

**图B1 · 光位错误版（旧截图→照片+换穿搭+换场景）**

```
参考这张视频截图里的人物（相貌、体型、身高163cm），生成一张新的照片。要求：

1. 人物保持跟截图里一样，但画质要从"视频截图"变成"手机实拍照片"的质感
2. 穿搭换成：[在这里描述沙面那套穿搭，比如"白色短袖T恤+浅蓝色直筒牛仔裤+白色运动鞋"]
3. 场景换成广州沙面，欧式老建筑外墙，下午阳光
4. 光线做错：太阳在人物正前方，背景过曝发白，脸部被直射光打出硬阴影，看起来很业余
5. 竖屏3:4，不要修图感，要像不懂拍照的人用手机随手按的
```

**图B2 · 支架高度错误版（旧截图→照片+换穿搭+换场景）**

```
参考这张视频截图里的人物（相貌、体型、身高163cm），生成一张新的照片。要求：

1. 人物保持跟截图里一样，但画质要从"视频截图"变成"手机实拍照片"的质感
2. 穿搭换成：[在这里描述沙面那套穿搭]
3. 场景换成广州沙面，欧式老建筑外墙，下午阳光
4. 拍摄角度做错：相机位置高于眼睛从上往下俯拍，人物显得矮胖、头大身小、腿压缩变短，地面占比过多，构图失衡
5. 竖屏3:4，真实手机照片质感，不要修图感
```

---

### 使用建议
- 方案A更简单（不用描述穿搭），方案B可以把旧素材盘活
- 生成后选最像手机实拍的（不要完美，要有粗糙感）
- 剪辑时给AI图叠加「噪点」或「微模糊」，削弱AI感
- 画面停留不超过2秒，快速切走没人细看
- 如果GPT生成的脸跟你本人差距太大，直接拿旧视频截图原片用，标注「以前的拍法」更真实
