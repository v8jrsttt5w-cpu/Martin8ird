# 脚本库

> 按账号归档脚本，按类型目录只做特殊场景补充。`短视频脚本模板.md` 是写新脚本时套用的模板。

---

## 目录结构

```
脚本库/
├── 短视频脚本模板.md    # 4套模板（摄影教学/穿搭展示/Vlog/带货测评）
├── 马丁鸟/              # 大号脚本：摄影教学+穿搭展示+器材横评
├── 马丁老师/            # 小号脚本：带货测评+直播话术
├── 商务脚本/            # 商单/品牌合作专用
├── 直播脚本/            # 完整直播流程专用
└── 短视频脚本/          # 历史规划目录，默认不新增正文
```

---

## 归档规则

| 内容类型 | 存放位置 | 命名规则 |
|----------|----------|----------|
| 马丁鸟普通短视频 | `马丁鸟/` | `选题标题.md` |
| 马丁老师挂车视频 | `马丁老师/` | `商品名-挂车.md` |
| 商单/送拍 | `商务脚本/` | `YYYY-MM-DD-品牌名-合作主题.md` |
| 直播整场脚本 | `直播脚本/` | `YYYY-MM-DD-商品名-直播脚本.md` |
| 类型索引/历史规划 | `短视频脚本/` | 只放README或索引，不重复存正文 |

---

## 工作流

1. 写脚本 → 选模板 → 填内容 → 存对应账号目录
2. 发布后 → 在 `已发布内容/` 新建发布归档，不搬走原脚本
3. 7天后回填数据 → 爆款内容同步写入 `02-账号运营/马丁鸟/爆款复盘/`
4. 有效钩子/金句/结构 → 反哺素材库和方法论文档
