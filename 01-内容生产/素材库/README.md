## 触发指令
| 指令 | 触发 |
|------|------|
| `写脚本` | 确认账号→选模板→检索素材→生成脚本 |
| `生成标题` | 基于方法论生成3-5个标题 |
| `优化开头` | 读取完播率数据→优化前5秒 |
| `找素材` | 全局搜索钩子/金句/结构 |

## 输入 → 输出
- **输入**：选题（来自子系统1）、博主需求
- **输出**：完整脚本、标题选项、优化后的开头
