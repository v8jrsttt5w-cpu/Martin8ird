## 使用规则

- 摄影教学 → 温情区选，音量25%不压口播
- 穿搭展示 → 节奏感强区选
- 带货 → 轻松日常区选
- 钩子 → 悬疑区选，3秒后切走
- 热点跟拍 → 直接蹭热歌榜当前排名

## 工作流

```
拍之前 → 抖音搜歌名 → 收藏 → 剪的时候直接用
剪完发布 → 回本库标注「✅已验证」或「❌搜不到」
```

> ⚠️ 本库大部分歌待验证。以后每次用到一首就回来打个✅，用不到3个月的歌直接删。
