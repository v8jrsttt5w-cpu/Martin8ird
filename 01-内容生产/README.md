# 子系统 1：选题引擎 🎯

> 从碎片想法到发布排期的完整流水线。

## 核心流程
```
碎片想法 → 选题收集箱 → 素材检索 → 选题深化 → 脚本初稿 → 发布计划
```

## 文件结构
| 文件 | 用途 | 当前状态 |
|------|------|---------|
| `选题管理/00-选题收集箱.md` | 所有想法的收件箱 | ✅ 已积累，需定期清理 |
| `选题管理/01-待深化的选题/` | 正在开发的选题 | 🟡 空目录，待承接深化稿 |
| `选题管理/02-本周发布计划.md` | 本周排期 | ✅ 已建 |
| `素材库/待剪辑素材库存.md` | 已拍未剪素材库存 | ✅ 与 DAILY-BRIEF 同步为10条 |
| `脚本库/马丁鸟/` | 大号短视频脚本 | ✅ 15篇 |
| `脚本库/马丁老师/` | 小号带货脚本 | ✅ 3篇 |
| `脚本库/短视频脚本/` | 旧规划目录 | ⚠️ 当前为空，后续建议废弃或改索引 |
| `选题管理/03-月度选题规划.md` | 月度主题规划 | ⏳ 待建 |

## 触发指令
| 指令 | 触发 |
|------|------|
| `记录选题` | 想法存入收集箱，自动关联素材库 |
| `深化选题` | 检索素材→推荐复用→生成脚本初稿 |
| `本周计划` | 查看/更新本周发布排期 |
| `探索选题` | 对标爆款分析→推荐5个选题 |

## 输入 → 输出
- **输入**：博主的碎片想法、热点事件、对标分析
- **输出**：结构化选题、脚本初稿、发布排期

## 关联系统
- ← 子系统5 竞品雷达（热点+对标选题）
- → 子系统2 创作工坊（脚本生成）
- → 子系统4 数据驾驶舱（发布后数据反哺选题）
