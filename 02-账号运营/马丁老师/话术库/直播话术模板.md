# 直播话术模板

> 马丁老师直播专用。已验证的高转化结构，每次直播前过一遍。

---

## 一、开场话术（前 5 分钟）

### 模板 A：聊天式开场
```
"来了来了，今天不整那些花里胡哨的。
我先把今天要讲的品都上身一遍给你们看。
老粉都知道我身高 165 体重 [X]，你们参考尺码就行。"
```

### 模板 B：痛点式开场
```
"兄弟们在不在？问你们一个问题——
买裤子是不是经常这样：
腰合适裤长拖地，裤长合适腰穿不进？
今天这条就是专门解决这个问题的。"
```

### 开场核心要素
- 前 30 秒说清楚「今天带什么品」
- 报自己身高体重（新粉不知道）
- 别喊「欢迎各位宝宝」，马丁老师人设是穿搭顾问不是销售

## 二、产品介绍话术（每个品 15-20 分钟）

### 结构：上身穿 → 细节讲 → 尺码推 → 场景化

### 上身展示
```
"先给你们看上身效果。我现在穿的是 M 码。
你们可以看——裤长刚好到脚踝，不会堆。
腰围正好，不用系皮带硬勒。
这是小个子穿裤子的黄金长度。"
```

### 细节介绍
```
"翻过来给你们看细节——
[展示腰部/裤脚/拉链/面料]
这个面料是 [材质]，你们摸不到我帮你们摸。
垂感很好，不容易皱，坐一天办公室也不会膝盖鼓包。"
```

### 尺码推荐
```
"我 165/[X]斤，穿 M 刚好。
如果你 160-165，选 M。
165-170，选 L。
170 以上，这个品不适合你，不用硬买。
我只推适合小个子的。"
```

### 场景化
```
"这条裤子你能穿什么场合？
上班穿，配白衬衫，干练。
约会穿，配深色上衣，显瘦。
周末穿，配 T 恤，舒服。
一条裤子三个场景，不亏。"
```

## 三、逼单话术

### 模板 A：限时型
```
"这个品今天播完就下架了，不是饥饿营销，
是真的库存就这么多，工厂那边小尺码做不了太多。
橱窗里有链接，现在拍今天发。"
```

### 模板 B：尺码稀缺型
```
"M 码还剩 [X] 件，小个子男生最合适的尺码。
这个品我自己穿了 [X] 天，洗了 [X] 次，版型没垮。
我自己衣柜里留了 2 条。"
```

### 模板 C：价格对比型
```
"你们去淘宝搜类似款，100 块以下的——
不是面料差就是版型松。
这条 [X] 块，对标的是商场 300+ 的品质。
你花这个钱，买到的是合身。"
```

### 逼单禁忌
- ❌ 不喊「家人们冲冲冲」
- ❌ 不说「再不买就没了」（太假）
- ✅ 用事实逼单：尺码数据、库存实况、自己穿的体验

## 四、互动话术

### 引导评论
```
"买了的兄弟评论区扣 1，我看看有多少人"
"不确定尺码的，把你的身高体重发评论区，我帮你看"
"想让我测什么品，评论区打出来，我去找"
```

### 回答常见问题
```
Q: "会不会缩水？"
A: "我机洗了 5 次实测，没缩。但别用热水，冷水洗。"

Q: "适合什么季节？"
A: "现在这个季节刚好，春秋单穿，冬天里面加秋裤。"
```

## 五、转场话术

```
"好了这个品讲完了，链接在橱窗，M 码快了。
下一个品是什么？
——还是裤子。为什么又是裤子？
因为小个子最难买的就是裤子。
这件跟上件不一样的是……"
```
