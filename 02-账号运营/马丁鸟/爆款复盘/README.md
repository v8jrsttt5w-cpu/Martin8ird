## 发现的公共规律

1. **"保姆级+一个具体动作"是最稳定爆款公式** — 不是"拍照技巧"，是"靠杆怎么拍""对镜怎么拍"
2. **前5秒40%是生死线** — 四期爆款全部过线
3. **收藏率是检验实用价值的核心指标** — 对镜拍43-74%、靠杆54%
4. **同标题模板使用上限约3-4次** — 之后必须换场景或标题壳
5. **标题够强可以弥补开头弱** — 阴天那期前5秒33%但选题+标题拉起来了
